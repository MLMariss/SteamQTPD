Pipeline monitor

How fresh and how complete the Steam data behind QTPD is, over time. A snapshot is recorded after every catalog scrape and every price pass (about hourly); history before 25 Oct 2026 is rebuilt from the repository at one point a day. Tap or hover ⓘ for what a number means.

Catalog

Released games stored in games.json at each snapshot. It grows as the scraper finds new releases; unreleased games wait outside it until they come out.

Time since each file was refreshed

How long before each snapshot the file was last written: the line climbs while the file waits and drops when its job writes it again, so a line that keeps climbing is a job that stopped writing. The figure on each card is that age at the latest snapshot; ⓘ says which job writes the file, how often, and what range is normal. GitHub skips or delays many scheduled runs on this repository, so a file sitting a few hours past its schedule is usually not a fault; one that keeps climbing past its normal range is.

How old the per-game data is

Every game carries the time its data was last fetched. Half the games were fetched more recently than the median, 95% more recently than the 95th percentile. Each source has its own refresh rule, so how old is normal differs per card. The split of review counts by release age starts on 26 Oct 2026; before it only the all-games line was recorded.
